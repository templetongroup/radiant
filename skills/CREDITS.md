# Credits — bundled skills

`library.json` lists the skills that ship inside Radiant. Two of them
(`architecture-map`, `har-derived-api-client`) are Templeton's own.

The rest come from **ECC** — https://github.com/affaan-m/ecc — a library of
several hundred agent skills. They were curated down to the ones that fit a Mac
coding harness, and are redistributed unchanged under the MIT license below.

Radiant itself is MIT, © 2026 Templeton Technologies. Nothing here is executed:
a skill folder is read by the agent, and Radiant refuses to install one that
contains a runnable file.
